# 阿萨尔运维守则（2026-10-29 定）

## 核心原则：少折腾
每次重启/重新登录都有触发腾讯风控的风险——先被降速（回复变慢），再被踢线（要重新扫码）。
2026-10-28 晚的教训：一夜反复更新重启三四次 → 全功能变慢 → 凌晨彻底掉线。

## 铁律
1. **顶多一天重启一次，顶多一天更新一次代码。**
2. 小改动先攒着：有问题先记下来，让我把代码写好、在沙箱里测完，攒到第二天一次性更新。
3. 不要"发现一点小问题就更新一次"。
4. 扫码登录一律用 `bash ~/azar_login.sh`，二维码自动存到相册 DCIM/Camera/asar_qr.png。
5. 怀疑掉线时，先在群里 @阿萨尔 实测一条，再查日志，不要一上来就重启。

## 排障口诀（按顺序，别跳步）
1. 群里实测能不能回复
2. `grep -i connect /root/bot/bot/bot.log | tail -3` 看有没有 connected
3. `tail -8 /root/napcat.log` 看有没有二维码/报错
4. 只有确认真的掉线了，才走 azar_login.sh 重新登录

## 已核实的事实（不用再怀疑）
- 模型 API（智谱 glm-4-flash）实测很快：短消息 1-2 秒，满人格+满记忆 3.4 秒
- NapCat 卡死判定：bot.log 里长时间无 "Bot 3427943187 connected"（该行 INFO 级必打印）
- "回复越来越慢然后掉线" = 连接不健康/被风控限流的征兆，不是代码问题
- 一块屏幕直接扫码不行；防冻措施已做过，不用再做
- 二维码 2 分钟过期，NapCat 会自动换新码，过期重新复制到相册即可
- glm-4-flash 面对不知道的问题**不会说"不知道"，而是自信地编**
  （问法拉杰的父亲，张口就编"法赫德·阿卜杜勒-拉赫曼"）——所以联网要主动搜，不能等它说不知道
- 联网检索用智谱官方 `web-search-pro`（同一个 API key，0.7 秒返回，结果准）
  **别用网页抓取**：百度几次就被"安全验证"拦，必应对中文问题经常跑偏
- ddgs 在沙箱里连不通（国外站点），手机上能用（搜图在用），但单次可能卡 20 秒

## pkill 防自杀技巧（重要！）
命令里带进程名的 pkill 会匹配到自己的命令行而自杀（Terminated/Exit 143）。
写法：`pkill -f "opt/QQ/[q]q"`、`pkill -f "[m]ain.py"` —— 用 [字] 打破自匹配。

## 养号守则（减少被踢）
- 少登录：一天最多一次重启/更新，掉线了才扫码
- 网络稳定：让阿萨尔长期固定在一种网络下（如家里 WiFi）
- 实名认证 + 平时在手机 QQ 上正常用这个小号（活跃度=信任度）
- 别让群友连环刷他（瞬间高频消息触发风控）
- 不乱升 NapCat 版本、不动登录凭证文件

## 掉线恢复顺序
1. bash asar_diag.sh 看结论
2. 先试免扫码重启 NapCat（一次就好，失败别重试）
3. 不行就走相册扫码（1 分钟）
